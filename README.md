# DeliciousFoodSearch

“周末吃什么”是一款帮助情侣发现附近美食、记录常吃店铺并跳转团购平台核实优惠的 Android 应用。

## 当前已实现

- 使用 Jetpack Compose 构建粉色系首页，采用圆角卡片、三栏入口和胶囊排序控件；设计结构参考公开的 Compose 美食 UI 项目，但不复制无许可证仓库的代码或图片。
- 用户明确同意隐私说明后，并行尝试 Android 系统网络定位与 GPS，选择最新且质量更好的单次位置；GPS 在室内超时会自动降级到可用的网络或近期位置，不进行后台持续定位。
- 使用高德官方搜索 SDK 获取当前位置 5 公里内的真实餐饮 POI。
- 首页分为“高德推荐”“历史常吃”“最实惠”：
  - 高德推荐保留高德返回的综合权重顺序，不把 weight 冒充为数值评分。
  - 历史常吃按本机“记为吃过”的次数和最近记录时间排序。
  - 最实惠按高德提供的参考人均价格升序排列，未知价格放在最后。
- 保留价格、味道、距离三个可解释的辅助排序入口。
- 点击“更新餐厅”后重新获取商家、评分、参考人均价、营业时间和距离，并显示加载、失败、重试及最后更新时间。
- 可按店名跳转美团或抖音搜索，由用户在目标平台核实当前团购。
- 拒绝定位时不会伪装成真实当前位置；用户可以明确选择“北京市中心”查看该区域的真实高德数据。
- 高德初始化、POI 映射和常吃记录读写不会阻塞 Compose 主线程；重复定位或刷新时只有最新一次请求可以更新页面。

## 数据边界

高德 Android 搜索 SDK 提供商家 POI、分类、评分、参考人均价、地址和营业时间等字段，但不提供美团或抖音的菜品与团购套餐价格。本项目不会抓取第三方页面，也不会伪造菜品或团购信息。

“高德综合权重”是高德搜索结果的排序能力，不是公开的可展示数值。应用只展示结果名次，并明确标注“不是评分”。

历史常吃记录保存在应用本机，不上传；精确用户位置不写入日志或历史记录。系统返回的 WGS84 坐标会在本机转换为高德搜索使用的 GCJ-02 坐标，中国大陆范围外保持原坐标。

## 配置高德 Android Key

复制 `local.properties.example` 中的配置格式，在项目根目录的 `local.properties` 添加：

```properties
AMAP_API_KEY=your_android_amap_key
```

Key 必须在高德开放平台绑定：

- Package Name：`com.zyb.deliciousfoodsearch`
- 当前 APK 所用签名证书的 SHA1

`local.properties` 已被 Git 忽略，不得把真实 Key 写进源码或提交到公开仓库。发布版本必须在高德控制台补充发布签名 SHA1。

## 依赖说明

- 高德搜索 SDK `com.amap.api:search:9.7.1`：附近餐饮 POI 搜索。
应用首次使用会先展示包含高德 SDK 数据用途的隐私说明。只有用户同意后才初始化高德搜索 SDK。

## 构建与验证

项目需要 JDK 17 或更高版本以及 Android SDK 37：

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
```
